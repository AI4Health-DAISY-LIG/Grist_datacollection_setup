Relevé technique de votre ordinateur

Étude AIadoption — Université Grenoble Alpes

Vous semblez être sur un téléphone ou une tablette.
Cette page mesure l'appareil depuis lequel elle est ouverte. Elle relèverait donc les caractéristiques de votre téléphone, et non celles de l'ordinateur sur lequel vous travaillez.

Que faire

Rouvrez cette même adresse depuis l'ordinateur que vous utilisez pour vos analyses, puis suivez les instructions.


      
      
Si vous n'utilisez jamais d'ordinateur
        pour ce type de travail, signalez-le à l'animatrice de la session : c'est en
        soi une information utile pour l'étude.

    

  


  
  

    

      
Ce que fait cette page

      
Elle relève quelques caractéristiques techniques de cet ordinateur, afin
        d'évaluer si les outils informatiques enseignés sont adaptés au matériel
        réellement disponible.

      
Rien n'est relevé tant que vous n'avez pas cliqué sur le
        bouton ci-dessous. Vous verrez ensuite l'intégralité de ce qui a été trouvé,
        avant de décider de le transmettre ou non.

    


    

      
Ce qui est relevé

      
    
        
  • le système d'exploitation et sa version
    • 
        
  • l'architecture du processeur et son nombre de cœurs
    • 
        
  • le modèle de carte graphique, lorsqu'il est lisible
    • 
      

      
Ce qui n'est jamais relevé

      
    
        
  • votre nom, votre adresse électronique, tout identifiant
    • 
        
  • le nom de votre ordinateur ou votre nom d'utilisateur
    • 
        
  • vos fichiers, votre historique, vos adresses réseau
    • 
        
  • aucun cookie, aucun traceur, aucune mesure d'audience
    • 
      

      
Cette page ne communique avec aucun
        serveur. Le relevé reste affiché sur votre écran ; c'est vous qui le copiez
        dans le formulaire, si vous le souhaitez. La participation est volontaire et
        sans conséquence d'aucune sorte.

    


    
  


  
  

    

      
Ce qui a été relevé

      

      
Les mentions « non déterminé » sont
        normales : votre navigateur ne donne pas accès à ces informations. Elles vous
        seront demandées dans le formulaire.

    


    

      
Donnée exacte qui sera transmise

      

      
C'est l'intégralité de ce qui partira. Rien d'autre.
